# 产品 API 与 Webhook 的集成说明

## 产品 API 的适用范围
产品 API 适用于明确需要 API 集成能力的客户，Team、Business 支持，Basic 不支持。本版目录确认能力是否提供，未说明具体接口、鉴权方式、限流和同步行为。客户提出某个接口、某种认证机制或某个调用量要求时，不能仅凭 API 受支持就认定这些细节成立。API 能力也不证明已经与客户的系统完成集成；本文是售前产品说明，不是可执行接口文档。需要技术参数的需求应保留原话和待确认细节，避免把实现方式补成新的购买条件或服务保证。

## Webhook 通知的适用范围
Webhook 通知适用于明确需要产品以 Webhook 发出相关事件通知的客户，Team、Business 支持，Basic 不支持。本版未列出事件清单、通知负载、投递时效和失败处理参数，因此不能承诺任意事件都可通知，也不能推断某种重试或送达保证。Webhook 通知表达事件发出的能力，不自动等于客户系统与产品之间持续保持双向一致。若客户关心指定事件或处理可靠性，需继续保留这些具体要求，不能因套餐包含 Webhook 就把未说明的部分一并判定为支持。

## API 与通知承担不同用途
本节适用于同时考虑 API 与 Webhook 的 Team、Business 客户。API 集成和事件通知是两个分别记录的能力，介绍方案时应指出客户实际需要其中哪项或两项；Basic 对两项均不支持。收到事件通知与调用产品接口不是同一行为，不能用一项替代另一项，也不能从两项同时存在推导完整双向同步方案。本版资料没有提供集成步骤、第三方兼容清单或性能承诺。对客户已有系统如何配合，应先确认目标行为与尚待说明的细节，不将泛泛集成意愿补成已经实现的连接。

## 含糊的系统对接要求
本节适用于只提出“对接现有系统”而未说明方式的客户。“对接”可能涉及 API、事件通知、数据导出或其他尚未建模的行为，不能直接替客户决定为明确 API 需求。可先了解期望的数据流向和需要的动作，再保留哪些能力已明确、哪些技术细节尚未说明。Team、Business 对 API 和 Webhook 的支持只能说明对应能力存在，Basic 的数据导出也不能代替任何集成要求。若要求涉及未建模技术参数或目录外能力，应继续表达未知，不能通过改写需求得到表面的满足结论。
